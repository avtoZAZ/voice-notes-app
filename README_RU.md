Минималистичное приложение для голосовых заметок на Android с функцией преобразования речи в текст, вдохновлённое дизайном Nothing.

[🇬🇧 English version](README.md)

## ✨ Возможности

- 🎤 **Запись голоса** - Быстрая запись голоса одним нажатием
- 🗣️ **Распознавание речи** - Автоматическое преобразование речи в текст с помощью встроенного распознавания Android
- 📝 **Список заметок** - Просмотр всех голосовых заметок в удобном списке
- ✅ **Завершение заметок** - Отметка заметок как выполненных с плавной анимацией исчезновения
- 🎨 **Дизайн в стиле Nothing** - Минималистичный черный фон с красными акцентами
- 🔴 **Пульсирующая кнопка записи** - Анимированная кнопка микрофона показывает активную запись
- 🇷🇺 **Поддержка русского языка** - Встроенная поддержка распознавания русской речи
- 📱 **Виджет главного экрана** - Виджет быстрого доступа для мгновенной записи заметок
- 💾 **Локальное хранилище** - Все заметки хранятся локально в базе данных Room

## 🎨 Философия дизайна

Приложение следует минималистичному языку дизайна Nothing:
- **Цвета**: Глубокий черный фон (#0A0A0A), темно-серые тона (#1A1A1A, #2A2A2A), яркий красный акцент (#FF0000)
- **Типографика**: Лёгкий, современный шрифт Roboto
- **Анимации**: Плавные, осмысленные переходы
- **Интерфейс**: Чистый, не отвлекающий опыт

## 📥 Загрузка и установка

### Вариант 1: Загрузка из GitHub Actions

1. Перейдите во вкладку [Actions](../../actions/workflows/build-apk.yml)
2. Нажмите на последний успешный запуск workflow
3. Скачайте артефакт `app-debug`
4. Извлеките ZIP-файл, чтобы получить `app-debug.apk`
5. Перенесите APK на ваше Android-устройство
6. Включите "Установка из неизвестных источников" в настройках устройства
7. Установите APK

### Вариант 2: Сборка из исходного кода

**На Linux/Mac:**
```bash
# Клонируйте репозиторий
git clone https://github.com/avtoZAZ/voice-notes-app.git
cd voice-notes-app

# Соберите APK
./gradlew assembleDebug

# APK будет доступен по пути:
# app/build/outputs/apk/debug/app-debug.apk
```

**На Windows:**
```cmd
REM Клонируйте репозиторий
git clone https://github.com/avtoZAZ/voice-notes-app.git
cd voice-notes-app

REM Соберите APK
gradlew.bat assembleDebug

REM APK будет доступен по пути:
REM app\build\outputs\apk\debug\app-debug.apk
```

## 🛠️ Разработка

### Требования

- Android Studio Hedgehog или новее
- JDK 17
- Android SDK 34
- Gradle 8.2+
- Доступ к Google Maven Repository (dl.google.com)

**Примечание**: Для сборки проекта требуется доступ к Maven-репозиторию Google для загрузки Android Gradle Plugin и зависимостей. Если вы находитесь в сети с ограничениями, GitHub Actions автоматически выполнит сборку при отправке изменений в репозиторий.

### Технологический стек

- **Язык**: Kotlin
- **UI Framework**: Jetpack Compose
- **Архитектура**: MVVM (Model-View-ViewModel)
- **База данных**: Room
- **Асинхронность**: Kotlin Coroutines & Flow
- **Распознавание речи**: Android SpeechRecognizer API

### Структура проекта

```
app/src/main/java/com/avtozaz/voicenotes/
├── MainActivity.kt              # Главная активность с распознаванием речи
├── ui/
│   ├── MainScreen.kt           # UI экраны на Compose
│   └── theme/
│       ├── Color.kt            # Цвета приложения
│       └── Theme.kt            # Тема Material3
├── data/
│   ├── VoiceNote.kt           # Сущность данных
│   ├── NoteDao.kt             # Room DAO
│   └── NoteDatabase.kt        # База данных Room
├── viewmodel/
│   └── NoteViewModel.kt       # ViewModel для заметок
└── widget/
    └── VoiceNoteWidget.kt     # Виджет главного экрана
```

## 🚀 Использование

1. **Запись заметки**:
   - Нажмите на красную кнопку микрофона
   - Разрешите доступ к микрофону, если потребуется
   - Произнесите вашу заметку
   - Приложение автоматически преобразует речь в текст

2. **Завершение заметки**:
   - Нажмите кнопку галочки на любой заметке
   - Заметка плавно исчезнет и будет удалена

3. **Использование виджета**:
   - Долгое нажатие на главном экране
   - Добавьте "Виджет голосовых заметок"
   - Нажмите на виджет для быстрого открытия приложения
